## 🎉 First Official Release!

We're excited to announce the first official release of CrackingInterview - your AI-powered coding interview preparation assistant!

## ✨ Key Features

### 🎯 Interview Practice Modes
- **Text Mode**: Type or paste coding problems
- **Screenshot Mode**: Capture problems from your screen
- **Audio Mode**: Practice verbal interviews with voice input
- **Chrome CDP Integration**: Seamlessly capture content from Chrome tabs

### 🤖 AI Models
- **Free Tier**: Gemini 2.0 Flash (3 free calls)
- **Pro Tier**: GPT-4, Claude 3.5 Sonnet, Gemini 2.0 Flash (150 calls/month)
- **BYO API Key**: Use your own Gemini API key for unlimited free usage

### 📝 Smart Prompts
Six built-in prompt templates:
1. **Algorithm - Optimal**: Advanced algorithmic problem solving
2. **Algorithm - Beginner**: Step-by-step guidance for learning
3. **System Design**: Architecture and design discussions
4. **Code Review**: Code quality and improvement suggestions
5. **Explain Concept**: Technical concept explanations
6. **Verbal Interview (Audio)**: Optimized for voice interviews

Plus unlimited custom prompts!

### ⚡ Global Hotkeys
- **Command+1**: Quick solve with text
- **Command+2**: Screenshot and solve
- **Command+3**: Record audio and solve
- **Command+Shift+H**: Toggle stealth mode (hide/show app)
- **Command+Q**: Quit app
- Scroll controls for Chrome CDP
- Window movement controls

### 🎭 Stealth Mode
- Completely hide the app from screen and Dock
- Perfect for practicing during actual interviews
- Seamless show/hide with global hotkey
- Includes restart and visibility toggle scripts

### 💎 Pro Features
- **150 AI Calls/Month**: Professional usage quota
- **All AI Models**: Access GPT-4, Claude 3.5, and Gemini
- **Display Capture**: Capture entire displays (coming soon)
- **Priority Support**: Fast response to your questions

## 📥 Installation

### Standard Installation (Recommended)
1. Download `CrackingInterview-1.0.0-macOS.dmg`
2. Open the downloaded DMG file
3. Drag CrackingInterview to Applications folder
4. Open CrackingInterview from Applications
5. If prompted, click "Open" to trust the app

### First Launch
- macOS may show a security prompt on first launch
- This is normal for notarized apps downloaded from the web
- Click "Open" to confirm you trust the app
- The app will launch normally on subsequent opens

## 🚀 Quick Start Guide

### 1. Create Account
- Launch CrackingInterview
- Click "Sign Up" for a new account
- Or "Sign In" if you already have an account
- Verify your email address

### 2. Choose Input Method
- **Text**: Type/paste problems directly
- **Screenshot**: Capture problems from screen
- **Audio**: Record verbal problem descriptions
- **Chrome CDP**: Connect to Chrome browser

### 3. Select Prompt Template
- Choose from 6 built-in templates
- Or create your own custom prompt
- Audio input automatically uses "Verbal Interview" prompt

### 4. Start Solving!
- Input your problem
- Wait for AI analysis
- Review the solution
- Learn and practice!

## 🎓 Usage Tips

### For Beginners
- Start with "Algorithm - Beginner" prompt
- Use text input for clear problem statements
- Take time to understand AI explanations
- Practice with simple problems first

### For Interview Prep
- Use "Algorithm - Optimal" for technical interviews
- Practice with "Verbal Interview" mode for behavioral
- Try screenshot mode to simulate real interview conditions
- Use stealth mode to practice under pressure

### For System Design
- Use "System Design" prompt
- Provide context about scale and requirements
- Ask follow-up questions
- Document the architecture discussion

## 🛠️ Stealth Mode Setup

### Automatic (Recommended)
- Press **Command+Shift+H** to toggle visibility
- App hides from screen and Dock
- Press **Command+Shift+H** again to show

### Manual Scripts (Advanced)
Located in app installation directory:

**Hide App:**
```bash
./toggle-visibility.sh
```

**Restart App (if hidden):**
```bash
./restart-app.sh
```

## ⚙️ Configuration

### Hotkeys Customization
1. Open Settings (⚙️ icon)
2. Go to "HotKeys" tab
3. Click on any hotkey to change
4. Press your desired key combination
5. Click "Save"

### AI Model Selection
1. Open Settings
2. Go to "AI Config" tab
3. Select preferred model
4. Pro users can choose from all models

### Custom Prompts
1. Open Settings
2. Go to "Prompts" tab
3. Click "➕ Create New Prompt"
4. Enter prompt details
5. Save and select your prompt
